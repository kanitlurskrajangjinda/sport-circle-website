# Sport Circle 🏟️
**ระบบจองสนามกีฬาและบริหารจัดการคอร์ทออนไลน์แบบครบวงจร**

🌐 **Live Demo:** [https://sport-circle-website.onrender.com](https://sport-circle-website.onrender.com)

---

## 📋 ภาพรวมโครงการ (Overview)
**Sport Circle** เป็นแพลตฟอร์มเว็บแอปพลิเคชันสำหรับจองสนามกีฬา จัดการตารางเวลา บริหารสต็อกอุปกรณ์กีฬา สินค้าเสริม และตรวจสอบการเงินแบบเรียลไทม์ รองรับการใช้งานแบบแบ่งตามบทบาท (Role-based Access Control) ได้แก่ ผู้ใช้งานทั่วไป (User), เจ้าของสนาม (Owner), พนักงาน (Staff) และผู้ดูแลระบบสูงสุด (Admin) พร้อมระบบตรวจสอบสลิปโอนเงินอัตโนมัติด้วยปัญญาประดิษฐ์ (Google Gemini AI)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), Chart.js, Lucide Icons, html5-qrcode, html2pdf.js, docx.js
* **Backend:** Node.js (HTTP Server ใน `server.js`) พร้อม Endpoint ตรวจสอบสลิป (`/api/verify-slip`) ด้วย Gemini API (`gemini-3.5-flash-lite`)
* **Database & BaaS:** Supabase (PostgreSQL, Authentication, Storage)
* **Deployment:** Render (Web Service)

## ✨ ฟีเจอร์หลักของระบบ (Key Features)

### 1. ระบบผู้ใช้งานทั่วไป (User)
* **ค้นหาและกรองสนาม:** ค้นหาตามประเภทกีฬา (ฟุตบอล, แบดมินตัน, บาสเกตบอล, ฟุตซอล, วอลเลย์บอล) และกรองตามจังหวัดต่างๆ ทั่วประเทศไทย
* **จองสนามและเลือกอุปกรณ์เสริม:** ดูรูปภาพสนาม สิ่งอำนวยความสะดวก แผนที่ Google Maps เลือกวันที่และช่วงเวลาแบบเรียลไทม์ พร้อมเลือกเช่าหรือซื้ออุปกรณ์เสริม โดยระบบจะคำนวณและตัดสต็อกอัตโนมัติตามช่วงเวลาที่จอง
* **ตรวจสอบสลิปด้วย AI & E-Ticket:** อัปโหลดสลิปโอนเงิน ระบบจะให้ Gemini AI ช่วยตรวจสอบความถูกต้องของยอดเงินและสลิปอัตโนมัติ พร้อมรับตั๋วอิเล็กทรอนิกส์ (E-Ticket) ที่มี QR Code สำหรับนำไปแสดงหน้าสนาม
* **ประวัติการใช้งาน:** ตรวจสอบประวัติการจองและสถานะการเข้าใช้งานย้อนหลังได้ตลอดเวลา

### 2. ระบบเจ้าของสนามและแอดมิน (Owner & Admin)
* **แดชบอร์ดบริหารอุปกรณ์และการเงิน (`equip-dashboard.js`):** ศูนย์ควบคุม 6 แท็บหลัก ได้แก่ สต็อกสินค้า, รายการกำลังเช่า/คืน, รายงานชำรุด/ส่งซ่อม/ค่าปรับ, สรุปยอดเงินสด/เงินโอน (Cash Shift), บิลรวมลูกค้า (Folios) และสถิติกราฟรายงาน
* **การส่งออกรายงาน:** สามารถดาวน์โหลดรายงานสรุปสถิติ รายได้ และสต็อกในรูปแบบ PDF และ DOCX (Word) ได้ทันที
* **ตารางจองแบบเมทริกซ์ (Matrix Schedule):** ตารางแสดงสถานะสนามแบบเรียลไทม์รายชั่วโมง พร้อมระบบจองหน้างาน (Walk-in) และเพิ่มอุปกรณ์เสริมเข้าบิลย้อนหลัง
* **จัดการผู้ใช้และสิทธิ์:** กำหนดบทบาทผู้ใช้งานในระบบ (Admin, Owner, Staff, User) พร้อมภาพรวมแพลตฟอร์มและระบบรับแจ้งปัญหาจากผู้ใช้

### 3. จุดบริการหน้าสนาม / พนักงาน (Staff & Check-in)
* **ระบบสแกน QR เช็กอิน:** รองรับการใช้กล้องมือถือสแกน QR Code จากตั๋วลูกค้า หรือค้นหาด้วยเบอร์โทร ชื่อ และรหัสบิล เพื่อตรวจสอบตัวตนและกดเช็กอินเข้าใช้งานรายชั่วโมง

## 📂 โครงสร้างไฟล์ในระบบ (Project Structure)
* `index.html` : หน้าตาเว็บแอปพลิเคชันหลักรวมทุก View และ Modal ต่างๆ
* `app.js` : ชุดฟังก์ชันหลักของฝั่ง Frontend (Auth, Booking, State Management, UI Render, AI Slip Verification)
* `data.js` : โครงสร้างข้อมูลพื้นฐานและค่าตั้งต้นของระบบ
* `equip-dashboard.js` : แดชบอร์ดบริหารสนาม อุปกรณ์ และระบบรายงานสถิติขั้นสูงพร้อม Export PDF/DOCX
* `server.js` : Node.js เซิร์ฟเวอร์และ API endpoint (`/api/verify-slip`) เชื่อมต่อ Google Gemini AI
* `style.css` : สไตล์ชีตการตกแต่งหน้าจอธีมฟ้า-ขาว พรีเมียม ทันสมัย
* `package.json` : การตั้งค่าโปรเจกต์และ Dependencies
